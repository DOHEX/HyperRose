# HyperRose Documentation

这个目录只保存适合进入 Git 的项目资料：已经整理过的协议结论、架构说明和维护文档。

## 目录

- `protocols/`：耳机控制协议分析、命令表、响应格式和实现状态。

## 收录规则

- 可以提交：协议结论、字段表、少量脱敏十六进制样例、实现注意事项。
- 不要提交：完整 btsnoop/HCI 抓包、tshark JSON 导出、APK 解包产物、反编译源码、本地脚本、设备唯一标识和个人实验记录。
- 本地研究资料统一放在仓库内的 `.local/research/`，该目录被 Git 忽略。

协议文档可以引用 `.local/research/` 中的本地来源路径，方便开发者在自己的工作区复核，但这些原始材料不属于公开文档的一部分。
