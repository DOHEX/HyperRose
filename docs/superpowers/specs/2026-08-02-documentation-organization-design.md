# HyperRose 文档目录整理设计

日期：2026-08-02

## 目标

将 `docs/` 从个人逆向工作台整理为可提交 Git、可供维护者长期使用的项目资料目录，同时保留个人研究资料在仓库内但不纳入 Git。

整理后的约束：

- `docs/` 中除明确忽略的本地研究目录外，内容都应对项目、协议或维护有稳定价值。
- 协议知识进入 Git，原始抓包和临时分析产物不进入 Git。
- 不迁移个人资料到仓库外；个人资料统一放在仓库内的 `.local/`。
- 不让已提交文档引用 Git 中不存在的原始文件路径。

## 当前问题

当前 `docs/` 约 234 MB，且 `.gitignore` 直接忽略整个 `docs/`。目录同时包含：

- 可维护的协议说明，例如 BudsFeel MK2 和 EARFREE i7；
- btsnoop 原始抓包、tshark JSON 导出和操作记录；
- APK 解包结果、反编译源码、IDA/Frida 脚本和本地二进制；
- 耳机 SVG 和其他尚未确认是否被项目引用的素材。

这使协议文档无法进入 Git，也让文档目录的职责无法从目录结构中判断。

## 目录设计

```text
docs/
├── README.md
├── protocols/
│   ├── README.md
│   ├── budsfeel-mk2.md
│   └── earfree-i7.md
├── architecture/
│   └── ...
└── development/
    └── ...

.local/
└── research/
    ├── captures/
    ├── exports/
    ├── extracted/
    ├── scripts/
    └── notes/
```

### `docs/`

只保存经过整理、适合共享和评审的项目资料。第一阶段至少包含：

- `docs/README.md`：说明文档目录用途、分类规则和协议文档维护方式；
- `docs/protocols/README.md`：协议索引、设备、传输方式、实现状态和待确认事项；
- 两份现有协议文档，改名并迁入 `docs/protocols/`；
- 后续只有形成稳定结论的架构或开发说明才进入 `architecture/`、`development/`。

协议文档可以保留少量脱敏的十六进制帧、字段表和可复核的示例。完整抓包、设备地址、临时操作时间线和其他仅用于个人逆向过程的材料不进入 Git。

### `.local/`

仓库内个人工作资料目录，不作为项目文档。用于保存：

- 原始 btsnoop/HCI 抓包；
- tshark/脚本导出的 JSON；
- APK 解包和反编译产物；
- IDA、Frida 等临时分析脚本及输出；
- 尚未整理成结论的笔记、操作顺序和实验素材；
- 只服务于本地开发的图片或二进制资源。

`.local/` 整体加入 `.gitignore`。整理过程中只移动和归档现有资料，不修改协议实现逻辑。

## Git 与引用规则

1. 删除 `.gitignore` 中对整个 `docs/` 的忽略规则。
2. 增加 `.local/` 的忽略规则。
3. 如需防止研究资料误放进 `docs/`，可额外忽略明确的原始格式和解包目录，但不使用会覆盖 `docs/**/*.md` 的宽泛规则。
4. 协议文档中的原始资料引用改为：采集设备、采集日期、协议结论和本地研究资料相对路径说明，例如 `.local/research/captures/<name>`；不引用迁移后不存在的 `docs/i7/1.json`。
5. 任何进入 Git 的文档都不得包含不必要的个人隐私、设备唯一标识或无法公开的路径；必要时用占位描述或脱敏值。

## 迁移范围

第一阶段只整理文档和资料边界：

- 将 BudsFeel MK2 与 EARFREE i7 协议 Markdown 迁入 `docs/protocols/`；
- 创建两个索引 README；
- 将现有抓包、JSON、解包目录、临时脚本、操作记录和未被引用的素材归档到 `.local/research/`；
- 更新协议文档中的路径和状态说明；
- 更新 `.gitignore`；
- 检查 Git 视角下 `docs/` 是否只剩可提交资料。

不在本次范围内：

- 修改 Kotlin 协议实现；
- 重新逆向或补抓协议；
- 将完整原始抓包纳入 Git；
- 引入 Git LFS；
- 重写协议结论之外的项目文档。

## 验收标准

- `docs/` 中的文件均属于项目文档、协议参考或明确维护资料，并可正常加入 Git；
- `.local/` 中的个人研究资料不会出现在 Git 未跟踪文件列表中；
- 两份协议文档仍保留其现有结论、待确认项和示例；
- 协议文档不再依赖迁移前的 `docs/i7/...`、`docs/liuli u/...` 等路径；
- `git check-ignore` 能确认 `.local/` 被忽略，且协议 Markdown 不再因规则被忽略；
- 不改动应用源码和运行时行为。
